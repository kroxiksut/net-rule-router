# Дорожная карта

Куда движется NetRuleRouter. Дат нет: пункт выходит, когда готов и проверен на
настоящих машинах.

Что уже работает — в разделе **Возможности** [README](README_RU.md).

## Первая публичная альфа: Windows и Linux

**Linux.** Платформенные части вынесены за отдельный интерфейс на каждую
возможность, поэтому общая логика решений уже работает без изменений; осталось
закончить сторону Linux и проверить её на уровне релиза, на x86-64 и ARM.

**Полноценный IPv6.** Правила уже называют IPv6-адреса и имена, которые в них
разрешаются, и маршрутизируют и защищают их так же, как IPv4. Осталось
проверить это в настоящих IPv6-сетях, прежде чем считать готовым.

## План развития

Порядок примерный: пункт может выйти раньше, позже или оказаться ненужным.
Нужно что-то из списка или чего-то в нём нет — откройте issue и опишите, какую
задачу решаете: это может поднять приоритет.

| Что | Что это даёт | Приоритет |
|---|---|---|
| Проверка недоступного сайта | Одна кнопка проверит сервер через основное и дополнительное подключение и скажет, что происходит: сервер не отвечает вовсе, его пропускает только одно из ваших подключений или сейчас всё работает | высокий |
| Восстановление сети при остановке службы | Если фоновая служба остановилась, окно, трей и терминальный интерфейс сразу скажут об этом и предложат запустить её снова или вернуть сеть без неё | высокий |
| Свой защищённый DNS для отдельной программы | Программа со своим шифрованным DNS, например корпоративный клиент или игра, работает, а защита остальных программ остаётся включённой | высокий |
| Сообщение о новой версии | Программа сообщает, что вышла новая версия, — по запросу или сама раз в две недели; автоматическую проверку можно выключить | средний |
| Обновления импортированных наборов правил | Если в новой версии в набор правил, который вы импортировали, добавлены адреса (например, новые адреса `site.com`), программа предложит обновление и покажет, что изменилось. Без вашего согласия ничего не меняется | средний |
| Защита от DNS-rebinding | Веб-страница не сможет через браузер добраться до роутера и домашних устройств. Имена, которые ваша сеть законно направляет на локальные адреса, продолжат работать, а задержанное можно разрешить одним щелчком | средний |
| Подключения, заданные при установке | Тихая установка называет основное и дополнительное подключение, и одинаковые компьютеры маршрутизируют по вашим правилам сразу после установки, ничего не нажимая | средний |
| Защита от утечки, заданная при установке | Тихая установка задаёт уровень защиты от утечки, и каждый пользователь каждого компьютера защищён с первого входа | низкий |
| Репозитории пакетов для Linux | Установка и обновления так, как принято в вашем дистрибутиве: `apt` в Ubuntu и Debian, `dnf` в Fedora, RHEL, AlmaLinux и Rocky Linux, `zypper` в openSUSE, AUR в Arch Linux, затем магазины приложений Astra Linux и РЕД ОС | средний |
| Установщики для компьютеров на ARM | Установщики EXE и MSI для Windows на ARM и пакеты `.deb` и `.rpm` для 64-битного ARM Linux — после проверки на настоящих ARM-машинах. До тех пор на ARM работают переносимые сборки | средний |
| NetRuleRouter на вашем VPN-сервере | Установленный на сервер с WireGuard или AmneziaWG, разводит по вашим правилам трафик клиентов этого сервера — телефона, ноутбука или домашнего роутера, подключённого к нему, — без установки чего-либо на них. Проверим такую настройку и опишем её по шагам | средний |
| Свежие версии библиотек | Библиотеки контрольных сумм, подписей и кодирования данных переходят на текущие версии, а правила и журнал аудита, сохранённые прежними версиями, продолжают работать без изменений | средний |
| Установка программы без сети | Запустите установщик из окна или терминального интерфейса, и ни он, ни всё, что он запустит, не выйдут за пределы компьютера, пока установка не закончится. Сеть вернётся сама, а программа предложит правила для того, что установилось. Пункт в контекстном меню проводника появится, если о нём попросят | средний |
| Правила по учётной записи службы | Сайты и службы, работающие внутри одной серверной программы, всё же можно разводить по разным подключениям — по учётной записи, под которой работает каждый, например по отдельному пулу приложений на сайт. Нужны права администратора; системные учётные записи остаются под защитой | средний |
| Такая же защита в Linux при падении подключения | Когда дополнительное подключение упало, обычные сайты в Linux остаются доступными, а защищённые вашими правилами — закрытыми, как в Windows | средний |
| Защита возвращается сама после перезапуска брандмауэра Windows | Если служба брандмауэра Windows перезапустится, пока работает NetRuleRouter, защита сразу ставится заново, а окно сообщит об этом, — компьютер не останется без защиты | средний |
| Строгие сетевые проверки в системах семейства RHEL | В RHEL, РЕД ОС, AlmaLinux и похожих системах с включёнными строгими сетевыми проверками сайты, которые ваши правила отправляют через дополнительное подключение, работают у каждого пользователя компьютера | средний |
| Страницы возвращаются вместе с VPN | Страница, которая не открылась, пока дополнительное подключение было недоступно, открывается сама, как только оно вернётся, без ручного обновления | средний |
| Правила для всего компьютера | Один набор правил для всех программ компьютера, включая службы и программы, которые работают, когда никто не вошёл. Включает администратор | средний |
| Имена сайтов тоже ждут, когда ВПН упал | При защите от утечки «Всё», пока дополнительное подключение недоступно, даже запросы имён сайтов ждут его, а не уходят через основное | средний |
| Шлюз для устройств домашней сети | Компьютер с NetRuleRouter по тем же правилам разводит трафик телефона, телевизора и других устройств | низкий |
| Предупреждение о подмене ответов об именах | Сообщение, если публичная сеть Wi-Fi или провайдер подменяет ответы об именах сайтов | низкий |
| Свой маршрут для контейнеров и виртуальных машин | Docker, Podman и локальные виртуальные машины получают маршрут так же, как программа, с той же защитой, если подключение пропадёт | низкий |
| Поиск имён раздельно для каждого пользователя | Если за компьютером одновременно работают несколько человек, защита от утечки одного никак не меняет то, как программы другого находят адреса сайтов | низкий |
| Трафик по пользователям машины | Сколько трафика у каждого пользователя компьютера, а не только по подключениям | низкий |
| Контейнеры под той же защитой, что и компьютер | При защите от утечки «Всё» и дополнительном подключении как маршруте по умолчанию WSL, контейнеры и виртуальные машины держатся на нём так же строго, как сам компьютер | низкий |
| Больше приватности между пользователями одного компьютера | То, что программа сообщает одному пользователю, никогда не выдаёт, насколько заняты другие | низкий |
| Окно от имени администратора работает только со своими файлами | Окно, запущенное от имени администратора, берёт данные только из файлов, которые создало само, и никогда из файлов, которые могла изменить другая программа вашего сеанса | низкий |
| Усиленный фокус и упрощённые подписи | Необязательная толстая рамка вокруг элемента с фокусом и более короткие подписи в окне, чтобы легче читать | низкий |
| Предупреждение о лимите тарифа | Уведомление, когда расход дополнительного подключения подходит к лимиту VPN-подписки или мобильного тарифа | низкий |
| Предложения для программ | Программа, у которой соединения не проходят по основному подключению, получит предложение перейти на дополнительное, как сейчас сайты | низкий |
| Проверка канала | Одна кнопка покажет, не теряет ли VPN-подключение крупные пакеты, и что поменять в настройках VPN-клиента | низкий |
| История изменений правил | Каждое добавленное, удалённое или изменённое правило — когда и откуда, и отмена любой одной правки по отдельности | низкий |
| Уведомление, когда другая программа удаляет ваши маршруты | Когда другая программа, например корпоративный ВПН со своими принудительными маршрутами, раз за разом удаляет маршруты, нужные вашим правилам, окно и терминальный интерфейс один раз скажут, каких сайтов это касается и какая программа мешает | низкий |
| Предупреждение о чужом широком маршруте | Когда другая программа, например менеджер виртуальных машин, забирает себе целый диапазон адресов, приложение покажет, какие адреса он перехватывает, и предложит убрать этот маршрут, чтобы сервер или сайт снова открывался | низкий |
| Консоль для всех пользователей компьютера | `nrr-cli` можно одной кнопкой в окне добавить в путь поиска команд для всех пользователей компьютера, а не только для своей учётной записи | низкий |
| Права администратора из терминального интерфейса в Windows | Если изменению в терминальном интерфейсе нужны права администратора, Windows спросит их обычным окном, и перезапускать терминал от имени администратора не придётся | низкий |
| Графики трафика по подключениям | Статистика трафика, которую уже можно выгрузить, — графиком в окне программы и в терминальном интерфейсе | низкий |
| Повтор поиска имени тем же подключением | Если поиск имени сайта приходится повторить, повтор идёт через то же подключение, что и первая попытка, — то, которое ваши правила выбрали для сайта | низкий |
| Компьютеры под доменной политикой компании | Если политика домена компании берёт на себя поиск имён на компьютере, программа заметит это и скажет в окне и терминальном интерфейсе, что ограничено и почему, а не будет молча работать с ослабленной защитой | низкий |
| Соединения IPv6 сразу следуют за изменением правила | После изменения правила уже открытые соединения по IPv6 сразу переходят на новый маршрут, как и по IPv4, в Windows и в Linux | низкий |
| Предупреждение о правиле, которое уже покрыто | Когда вы добавляете правило для сайта или программы, которые уже покрывает другое правило, программа назовёт это правило и спросит, добавлять ли новое всё равно | низкий |
| Окно и трей легче | В окне и трее только тот код, который им нужен: загрузка меньше, и меньше кода внутри может добраться до ваших настроек | низкий |
| Подделать ответ об имени труднее | Поддельный ответ на поиск имени из недоброжелательной сети гораздо реже примут за настоящий | низкий |
| Корпоративный VPN через выбранное подключение без ручных правок | Когда компания меняет адреса своих VPN-шлюзов, маршрут к ним меняется сам, и править правило вручную не нужно | низкий |
