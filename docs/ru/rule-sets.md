# Как сохранить правила и загрузить их обратно

[English](../en/rule-sets.md) · **Русский**

Здесь показано, как сохранить свои правила в файл, загрузить готовый список для
своей страны и перенести правила на другой компьютер.

## Что такое набор правил

Набор правил — это ваш список правил, сохранённый в двух небольших текстовых
файлах: один для основного подключения, другой для дополнительного (обычно
VPN). Программа поставляется с готовыми наборами для нескольких стран. Можно
сделать и свои, например «дом» и «работа». В файлах хранятся только правила;
они не запоминают, какое из ваших подключений — VPN.

## Сохранить свои правила

Сделайте это один раз — и правила в безопасности, даже если вы переустановите
программу.

1. Нажмите **Настройки** в левой колонке, затем **Файлы правил и настроек**.
2. В блоке **Мои наборы правил** нажмите **Обзор...** и выберите свою папку,
   например в «Документах». Не выбирайте папку самой программы: при обновлении
   она заменяется вместе с вашим набором.
3. Нажмите **Сохранить текущие правила как набор...**.
4. Введите название, например `дом`, и нажмите **Сохранить набор**.

Теперь строка над правилами называется **Мой набор правил:** и показывает наборы
из вашей папки. Чтобы вернуться к сохранённому набору, выберите его там и
нажмите **Загрузить**.

Быстрее, из раздела **Правила**: нажмите **Сохранить правила...** и выберите
**Сохранить набором (оба подключения)…**.

## Загрузить готовый набор для своей страны

1. Нажмите **Правила** в левой колонке.
2. В строке **Готовый набор:** откройте список. Пока вы ничего не выбрали, там
   написано **Выберите набор правил...**.
3. Выберите свою страну и нажмите **Загрузить**.
4. Откроется окно **Просмотр изменений**. Прочитайте его и нажмите
   **Применить**.

**Ваши правила будут заменены.** В колонке **Удалено** видно каждое ваше
правило, которое пропадёт. Если хотите их сохранить, нажмите **Отмена** и либо
сначала сохраните их (см. выше), либо воспользуйтесь разделом «Добавить набор к
своим правилам» ниже.

Пока вы не нажали **Применить**, ничего не меняется.

Строки нет? Значит, её скрыли. Включите снова: **Настройки** → **Файлы правил
и настроек** → **Показывать готовые наборы правил над списком правил**.

## Добавить набор к своим правилам

1. В разделе **Правила** нажмите **Ещё...** и выберите **Загрузить список
   правил...**.
2. Выберите один или два файла `.txt` (по одному на подключение).
3. В блоке **Режим импорта** выберите **Объединить — добавить новые, пропустить
   дубли**. Ваши правила останутся; добавятся только недостающие.
4. Нажмите **Импортировать**, прочитайте **Просмотр изменений**, нажмите
   **Применить**.

## Перенести правила на другой компьютер

1. На первом компьютере: **Правила** → **Сохранить правила...** →
   **Сохранить набором (оба подключения)…**. Получится два файла.
2. Скопируйте файлы на другой компьютер (флешкой или через облачную папку).
3. На другом компьютере: **Правила** → **Ещё...** → **Загрузить список
   правил...**, выберите файлы и режим импорта, нажмите **Импортировать**, затем
   примените.

Сначала на другом компьютере нужно выбрать его подключения: см.
[Как выбрать основное и дополнительное подключение](connections.md).

## Начать без правил

- При самом первом запуске выберите в приветственном окне **Начать без правил**.
  При следующем запуске программа один раз предложит набор для вашей страны.
- Позже: **Правила** → **Ещё...** → **Очистить все правила...**. Это нельзя
  отменить, поэтому сначала сохраните правила.

## Если нужно больше

- Правила только одного подключения: в меню **Ещё...** есть выгрузка в файл
  только правил основного или только правил дополнительного подключения.
- Файлы можно править в любом текстовом редакторе:
  [Формат правил](rules-file-format.md). После правки нажмите **Ещё...** →
  **Обновить правила из файла**.
- Установка на много компьютеров: [Установка без вопросов](unattended-install.md).
- В терминальном интерфейсе, на экране **Правила**: `p` загружает набор для
  страны, `i` импортирует, `x` экспортирует: [терминальный интерфейс](tui.md).
