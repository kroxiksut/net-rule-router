# Поддерживаемые системы

[English](../en/supported-systems.md) · **Русский**

На чём работает первая альфа, в каком виде она туда ставится и на каких
системах её уже запускали. «Проверено» значит: установлено, работало с
настоящими правилами и удалено на этой системе. Остальное должно работать по
указанным причинам, но пока никто этого не подтвердил. Если вы запустите
программу там, где проверки ещё не было, issue о том, как прошло, поможет
больше всего.

## Windows

| Система | Поставка | Окно | Проверено |
|---|---|---|---|
| Windows 11, 64 бита (x64) | переносимый ZIP, установщик EXE, MSI | есть | да |
| Windows 10, 64 бита (x64) | переносимый ZIP, установщик EXE, MSI | есть | пока нет |
| Windows на ARM (ARM64) | переносимый ZIP, установщик EXE, MSI | есть | пока нет |
| 32-битная Windows | не поддерживается | — | — |

Установка фоновой службы один раз требует прав администратора; в повседневной
работе они не нужны.

## Linux

Службе нужны **systemd** и **nftables** — они есть во всех современных
распространённых дистрибутивах. Свои правила у каждого вошедшего пользователя
работают на ядре Linux 4.10 и новее; на более старом ядре правила одного
пользователя действуют для всех. Окну нужен **Qt 6.6 или новее** из системы;
там, где Qt старше, служба, консоль `nrr-cli` и терминальный интерфейс
`nrr-tui` работают без него.

| Система | Поставка | Окно | Проверено |
|---|---|---|---|
| Ubuntu 24.10 и новее | `.deb` | есть | Ubuntu 26.04 LTS: да |
| Ubuntu с 20.04 по 24.04 | `.deb` | нет (старый Qt) | пока нет |
| Debian 13 | `.deb` | есть | пока нет |
| Debian с 10 по 12 | `.deb` | нет (старый Qt) | пока нет |
| Astra Linux 1.8 | `.deb` | есть | без окна: да |
| Astra Linux 1.7 | `.deb` | нет (старый Qt) | да |
| РЕД ОС 8 | `.rpm` | зависит от версии Qt в системе | без окна: да |
| РЕД ОС 7.3 | `.rpm` | нет (старый Qt) | пока нет |
| RHEL 8 и новее, AlmaLinux, Rocky Linux, Fedora | `.rpm` | Fedora: есть; RHEL 8: нет | пока нет |
| Любой другой дистрибутив с systemd и nftables | `.tar.gz` | если есть Qt 6.6 | пока нет |

Пакеты собираются для 64-битных x86 (x86_64) и для 64-битного ARM (ARM64), с
окном везде, где в системе есть Qt 6.6. Пакеты ARM64 на живой системе пока не
проверялись.

## macOS

Пока не поддерживается; появится после Linux (см. [дорожную
карту](../../ROADMAP_RU.md)).
