# Поддерживаемые системы

[English](../en/supported-systems.md) · **Русский**

На чём работает первая альфа, в каком варианте, в каком виде она туда
ставится и на каких системах её уже запускали.

Каждая система получает один из двух вариантов:

- **полный** — окно и трей, фоновая служба, консоль `nrr-cli` и терминальный
  интерфейс `nrr-tui`;
- **без окна** — служба, `nrr-cli` и `nrr-tui`, который даёт те же возможности
  из терминала.

Колонка «Проверено» говорит, откуда известно, что работает:

- **на машине** — установлено, работало с настоящими правилами и удалено на
  этой системе;
- **по документации** — совместимо по документации и репозиториям самого
  дистрибутива; своей тестовой машины под него мы не держим;
- **пока нет** — должно работать по указанным причинам, проверка на живой
  системе запланирована.

Если вы запустите программу там, где на машине её ещё не проверяли, пара слов
о том, как прошло, поможет больше всего: в
[issue](https://github.com/kroxiksut/net-rule-router/issues) или в
Telegram-канале [t.me/netrulerouter](https://t.me/netrulerouter).

## Windows

| Система | Архитектура | Вариант | Поставка | Проверено |
|---|---|---|---|---|
| Windows 11 | x64 | полный или без окна | переносимый ZIP, установщик EXE, MSI | полный: на машине |
| Windows 10 | x64 | полный или без окна | переносимый ZIP, установщик EXE, MSI | полный: на машине |
| Windows 11 на ARM | ARM64 | полный или без окна | переносимый ZIP | пока нет |
| 32-битная Windows | x86 | не поддерживается | — | — |

Установка фоновой службы один раз требует прав администратора; в повседневной
работе они не нужны.

## Linux

Службе нужны **systemd** и **nftables** — они есть во всех современных
распространённых дистрибутивах. Свои правила у каждого вошедшего пользователя
работают на ядре Linux 4.10 и новее; на более старом ядре правила одного
пользователя действуют для всех. Окну нужен **Qt 6.6 или новее** из системы;
там, где Qt старше, служба, консоль `nrr-cli` и терминальный интерфейс
`nrr-tui` работают без него.

| Система | Архитектура | Вариант | Поставка | Проверено |
|---|---|---|---|---|
| Ubuntu 24.10 и новее | x86_64, ARM64 | полный | `.deb` | Ubuntu 26.04 LTS: на машине |
| Ubuntu 22.04, 24.04 | x86_64, ARM64 | без окна (старый Qt) | `.deb` | пока нет |
| Debian 13 | x86_64, ARM64 | полный | `.deb` | пока нет |
| Debian 11, 12 | x86_64, ARM64 | без окна (старый Qt) | `.deb` | пока нет |
| Astra Linux 1.8 | x86_64 | полный | `.deb` | без окна: на машине |
| Astra Linux 1.7 | x86_64 | без окна (старый Qt) | `.deb` | на машине |
| РЕД ОС 8 | x86_64 | полный, если Qt в системе 6.6 или новее | `.rpm` | без окна: на машине |
| РЕД ОС 7.3 | x86_64 | без окна (старый Qt) | `.rpm` | пока нет |
| Fedora | x86_64, ARM64 | полный | `.rpm` | пока нет |
| RHEL 10, AlmaLinux 10, Rocky Linux 10 | x86_64, ARM64 | полный | `.rpm` | по документации |
| RHEL 8 и 9, AlmaLinux 8 и 9, Rocky Linux 8 и 9 | x86_64, ARM64 | без окна | `.rpm` | по документации |
| openSUSE Tumbleweed, openSUSE Leap 16 | x86_64, ARM64 | полный | `.tar.gz` | по документации |
| openSUSE Leap 15.6 | x86_64, ARM64 | без окна | `.tar.gz` | по документации |
| Альт p10, p11 | x86_64, ARM64 | полный, если Qt в системе 6.6 или новее | `.tar.gz` | пока нет |
| Любой другой дистрибутив с systemd и nftables | x86_64, ARM64 | полный, если Qt в системе 6.6 или новее | `.tar.gz` | пока нет |

Где Qt в системе старше 6.6, менеджер пакетов откажется ставить пакет окна и
назовёт, чего не хватает; поставьте более свежий Qt из своего дистрибутива или
оставьте вариант без окна (см. [Пакеты для Linux](packaging-linux.md)). Для ARM64
в выпуске только архивы `.tar.gz`, полный и без окна; пакеты `.deb` и `.rpm` для
ARM64 появятся позже. Ни одна сборка ARM64 на живой системе пока не проверялась;
всё «на машине» выше — x86_64.

## macOS

Пока не поддерживается; появится после Linux (см. [дорожную
карту](../../ROADMAP_RU.md)).
