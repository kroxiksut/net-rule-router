# Сторонние компоненты

[English](../en/third-party-components.md)

NetRuleRouter в основном состоит из собственного кода, но несколько частей взяты
у других авторов. На этой странице перечислено, что именно, зачем оно нужно и как
самостоятельно убедиться, что копия на вашем компьютере — подлинная.

Ту же информацию показывает и сама программа: **Справка → Лицензии → Сторонние
компоненты** (окно лицензий открывается также из окна «О программе» и из меню в
трее). Для каждого компонента видны автор, версия, лицензия, а для исполняемых
компонентов — где лежит файл, его контрольная сумма и кто его подписал.

## Что поставляется и зачем

| Компонент | Автор | Лицензия | Платформы | Для чего |
|-----------|-------|----------|-----------|----------|
| Wintun | WireGuard LLC | Wintun Prebuilt Binaries License | только Windows | Отдельные виртуальные адреса для сайтов (fake-IP) |
| Tabler Icons | Tabler | MIT | все | Иконки интерфейса |

Больше ничего отдельным файлом не поставляется. Библиотеки Rust, из которых
собрана программа, компилируются внутрь её исполняемых файлов и распространяются
под разрешительными лицензиями; полный список проверяется при каждой сборке.

### Wintun (только Windows)

Функция fake-IP выдаёт каждому сайту собственный адрес внутри программы, чтобы
маршрутизация и защита от утечек решались по сайту, а не по IP-адресу. Для этого
нужен сетевой адаптер, с которого программа может читать трафик. В Linux и macOS
такой адаптер есть в самой операционной системе, поэтому сборки для них не везут
ничего дополнительно. В Windows его нет, поэтому в сборку для Windows входит
Wintun — тот самый адаптер, который использует WireGuard и ряд известных
коммерческих VPN-клиентов.

Что из этого следует на практике:

- Wintun используется **только** функцией fake-IP. Если функция выключена,
  адаптер не создаётся.
- Если компонента нет, fake-IP сообщает о своей недоступности, а **всё
  остальное продолжает работать** — маршрутизация, правила, защита от утечек.
- Файл поставляется ровно в том виде, в каком его опубликовал автор, с его
  подписью. Проект его не изменяет, не пересобирает и не переупаковывает.

### Tabler Icons

Иконки интерфейса взяты из набора Tabler под лицензией MIT, которая требует
только указания авторства — этим и занимается окно лицензий. Собственный логотип
программы в этот набор не входит.

## Как убедиться, что компонент подлинный

Надпись «это оригинальный файл» в окне «О программе» ничего не доказывает,
поэтому программа проверяет это сама и показывает результат. Откройте
**Справка → Лицензии → Сторонние компоненты**. Для каждого исполняемого
компонента там будет один из вердиктов:

| Вердикт | Что означает |
|---------|--------------|
| Подлинный | Файл совпадает со сборкой, которая поставляется с программой, и подписан её автором. |
| Не совпадает | Файл не совпадает с поставляемой сборкой либо его подпись не подтверждена. Переустановите программу. |
| Не установлен | Компонента нет. Функция, которой он нужен, недоступна; на остальное это не влияет. |

Это та же самая проверка, которую программа выполняет перед загрузкой
компонента, поэтому окно не может показать зелёный вердикт файлу, который
программа откажется использовать.

Если хотите проверить вручную, показанных пути и контрольной суммы достаточно:

```powershell
Get-AuthenticodeSignature "<путь из окна>" | Format-List Status, SignerCertificate
Get-FileHash "<путь из окна>" -Algorithm SHA256
```

Подпись должна быть `Valid` и выдана WireGuard LLC, а контрольная сумма —
совпадать с показанной в окне. И то, и другое можно сверить с копией,
опубликованной автором на <https://www.wintun.net/>.
