# NetRuleRouter — Документация

[English](README.md) · **Русский**

![NetRuleRouter](images/logo-lockup-ru.png)

NetRuleRouter отправляет выбранные вами сайты и программы через второе
подключение (обычно VPN), а всё остальное — через ваш обычный интернет.

[Для продвинутых пользователей и администраторов →](ru/advanced.md)
