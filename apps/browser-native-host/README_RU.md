# Браузерный нативный хост

Этот экспериментальный компонент отвечает на диагностический запрос расширения. Ответ действует только до завершения хоста, не более 60 секунд после запуска. Он не подтверждает подлинность хоста, работу службы NRR или маршрут и не меняет настройки браузера или NRR.

Хост пока не регистрируется и не входит в готовый пакет продукта. Связь с браузером остаётся необязательной; расширение работает и без неё. Для регистрации, проверки подлинности службы и синхронизации нужны дальнейшая работа и проверка на поддерживаемых системах.
