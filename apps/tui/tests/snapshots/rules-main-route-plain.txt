Screen: Status
Service: OK
Rules status:
  Rules are working
  Your rules are working.
Connections:
  Main connection: Ethernet — Example Network Adapter — Available — Rules applied
  Additional connection (e.g. VPN): Example Tunnel — Example Network Adapter — Available — Rules applied
Notifications:
  No notifications.
Commands on this screen:
  r: restore your settings to a service that lost them
  t: confirm the first listed program as your VPN (T: with the programs it ships with), so leak protection keeps it working
  a: allow the first listed VPN to reach its server, so leak protection lets it connect
  p: confirm the suggested main connection; another one is chosen under Connections
  v: send the blocked site named under the state over the additional connection; you are asked first
  x N: dismiss notification N   X: dismiss all
  m N: stop showing notifications like N   H: hide or show addresses in block notifications
  For a blocked connection N: v N: send it over the additional connection   s N: snooze   w N: why it was blocked
  For a site that does not open in notification N: c N: check whether the network or the site is at fault
Type a screen number, h for help or q to quit, then press Enter.

Screen: Rules
Service: OK
Rule list:
  Reading the rules from the service…
  Connection: All connections
Rules:
Commands on this screen:
  a: add a rule
  e and a number: edit that rule, for example e 3
  d and a number: delete that rule
  t and a number: switch that rule on or off
  f: choose which connection's rules to show
  S: by state, y: by type, u: only added automatically, E: the rules that will not be applied, H: hide or show the rules that do not work
  / and text: search, for example / example.com; / alone shows all
  > and <: next and previous page
  s: apply the changes; they are shown first
  i: import files. x: export files. p: load a country rule set
  X: save one connection's rules to a file. L: add the demo rules. W: clear all rules (asks first)
  Z: go back to the baseline rules; your own rules and the changes on screen are dropped, and what changes is shown first
  *: select or unselect the chosen rule (in line mode * and numbers, for example * 2 5). B: act on the selected rules
  o: choose the folder with your rule sets
  r: show the rules the service applies
  b: switch between your own rules and the baseline
  m: move the rules that work only on the other connection. n: not now
  c: check whether the main connection reaches the sites of your additional-connection rules. O: list what it does not reach first, or back
  v: add a rule for a VPN's gateway
  g: connections for applications and devices
  F: compare your linked rules files with the rules in force and merge them
  C: remove the rules a wildcard rule of the same connection already covers
  A: add several rules at once
  T and a number: give that rule the type its value is, for example T 3. M: do it for every such rule
  R: recent changes. U: put a deleted rule back
  P and a rule number: confirm a protected rule, or take the confirmation back
Type a screen number, h for help or q to quit, then press Enter.
